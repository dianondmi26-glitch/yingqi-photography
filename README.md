# Yingqi Chen — Photography

A minimalist polar-photobook-style photography portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — website content
- `style.css` — layout, typography and responsive design
- `script.js` — subtle scroll reveal
- `assets/images/` — replace placeholder image names with your own photographs

## Image filenames

Put your exported web images in `assets/images/` using these names:

- `cover.jpg`
- `ice-edge-01.jpg`
- `ice-edge-02.jpg`
- `three-blues-01.jpg`
- `three-blues-02.jpg`
- `three-blues-03.jpg`
- `drift-pattern-01.jpg`
- `waterline-01.jpg`
- `human-time-01.jpg`
- `human-time-02.jpg`
- `full-bleed.jpg`

Recommended export:
- sRGB
- JPG or WebP
- long edge around 2800–3200 px
- quality around 80–88%

## Publish with GitHub Pages

1. Upload all files and folders to the repository root.
2. Open repository **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. GitHub will provide the public site URL after deployment.

## Edit

Open `index.html` and change:
- project text
- locations
- email
- Instagram URL
- PDF portfolio URL

All styling is in `style.css`.
